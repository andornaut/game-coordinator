## Scope

Apply the [toggle rule](../game-policies.md#controls-and-input) in Ada the Navigator, Archie and Chibi
through their existing Tech owners. Game Kit owns shared control changes where applicable.

## Criteria

- Verify both states render directly under the toggle in every relevant layout, including Settings
  and Cheats. Verify **Shown** and **Hidden** for display visibility and **On** and **Off** where
  they describe the setting. Change the displayed text when the toggle state changes.
- Preserve labels, accessible state, input behavior and persistence.
- Record checked source and normal delivery for each changed game. Track shared kit publication
  separately from each game's adoption.
