## Scope

Apply the [Settings install rule](../design/game-policies.md#installs) in Ada the Navigator, Archie and Chibi
through their existing Tech owners. The change belongs in each game's Settings caller.

## Criteria

- Verify one rendered **Install** button at the existing placement when eligible. Verify its
  accessible name, decorative down-arrow-to-tray icon, and absence of duplicate captions or
  standing help.
- Verify existing eligibility, input behavior and focus return. Confirm activation opens the native
  prompt when available or shows the existing browser-specific steps.
- Record the checked source revision and normal delivery for each changed game.

## Outcome

Browser checks found one accessible **Install** button with a decorative tray icon in each game.

- Ada the Navigator checked `41800b0a` and deployed `f0b33178`. Chromium verified the button
  at two widths, the native prompt trigger using a synthetic event, and the held browser steps
  with Back restoring focus to Install. The deployed icon mapping was verified online and offline.
- Archie checked `528a694a` and deployed `6e235277`. Chromium verified the existing browser
  steps opened once and Close restored focus to Install. Only test files changed between the
  checked runtime and deployed source.
- Chibi checked `16431836` and deployed `7831c26c`. Chromium verified the button at three
  layouts. Tap, hold and keyboard opened the existing browser steps, and closing them restored
  focus to Install. The checked and deployed Settings files and dependency lock have identical
  Git objects across distinct histories.
