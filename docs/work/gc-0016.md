## Scope

Apply the [Back, Close and Resume policy](../game-policies.md#back-close-and-resume) in every game. Each game's Tech owner coordinates source changes with Art and Gameplay. Game Kit maintains the shared input and modal mechanisms.

## Criteria

- Audit modal entry and exit routes, including title Menu, active Pause, nonpausable Menu, direct HUD dialogs and nested pages. Verify the destination, pause state, and focus for each supported dismissal control.
- In Archie, verify that Help and Logbook opened from a menu return to that menu. If Pause opened the page, gameplay stays paused until Resume.
- Click each visible black letterbox bar in wide and tall layouts. Confirm it runs the top modal's X action once, restores the same view and focus, and sends no click to the restored view. Verify that mandatory choices stay open.
- Preserve mandatory-choice protection, unsaved-change and confirmation guards, single-action dismissal, and existing shared modal isolation. Record already compliant routes with evidence and qualify changed routes through normal delivery and behavioral acceptance.
