## Scope

Apply the [Back, Close and Resume policy](../design/game-policies.md#back-close-and-resume) in every game. Each game's Tech owner coordinates source changes with Art and Gameplay. Game Kit maintains the shared input and modal mechanisms.

## Criteria

- Audit modal entry and exit routes, including title Menu, active Pause, nonpausable Menu, direct HUD dialogs and nested pages. Verify the destination, pause state, and focus for each supported dismissal control.
- In Archie, verify that Help and Logbook opened from a menu return to that menu. If Pause opened the page, gameplay stays paused until Resume.
- Click and tap each letterbox region outside the rendered viewport in wide and tall layouts. For both pages and modals, verify the topmost eligible active surface invokes its existing Back, Close or X action once, restores the correct view and focus, and consumes the input. Verify Previous is ineligible, a blocking surface without an available dismissal prevents fallthrough, and existing viewport input and gestures work as before.
- Keep modal-only letterbox proofs scoped to modals. Record separate page coverage for this rule.
- Preserve mandatory-choice protection, unsaved-change and confirmation guards, single-action dismissal, and existing shared modal isolation. Record already compliant routes with evidence and qualify changed routes through normal delivery and behavioral acceptance.
