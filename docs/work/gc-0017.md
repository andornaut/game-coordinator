## Scope

Apply the [shared focus appearance rule](../game-policies.md#controls-and-input) to game controls and mocks. Ada's purchase Cancel mock is the reference example. Game Kit owns shared control primitives that supply the outline. Existing game owners own caller styles and checks.

## Criteria

- Remove generic browser-style focus rings from the ordinary game presentation. Use a visibly distinct keyboard-focus state in the game's control styling and preserve visible focus in forced-colors modes.
- Preserve native focus, tab order, keyboard activation, focus restoration and the separate appearance of pressed, selected, disabled and ordinary graphic borders.
- Inspect actual pointer and keyboard routes and modal dismissal, including visible restoration. Record the affected shared primitive or caller, the checked appearance, and normal delivery or the exact blocker.
