## Scope

and Chibi. Each game Tech owner verifies the published site's instructions
against that game's current bindings.

## Criteria

- Use concise, accessible tables for the essential gameplay and menu actions.
- Arrow glyphs may supplement accessible key labels.
- Cover relevant pointer and touch controls where supported and keep the tables
  readable at narrow widths.
