## Scope

Apply the [source structure](../design/game-policies.md#source-structure) in Ada the Navigator, Archie and Chibi
through their Tech owners, from the structure audits ada-0393, adw-0258 and cwh-0310.
The import-guard end state also applies to Art Kit, Coordination Kit, Delivery Kit and Game Kit.

## Criteria

- Each game maps its directories onto the eight bands in its own layer table and records its remaining
  gaps as work items linked to gc-0029.
- Archie moves its pure UI kit to the Presentation band, above Model.
- Each game runs the import check during its migration with a known-violations table that only shrinks,
  removes it once the table is empty, and guards the layers with ESLint.
- Each kit guards its layers with ESLint and retires any permanent import-check script or test.
