## Scope

Simplify public game homepages under the
[shared homepage structure](../design/game-policies.md#game-homepage-structure).
This changes the footer step from gc-0037. Game Tech owners implement and
verify their sites. The playable UI keeps its existing navigation.

## Criteria

- Remove the footer from every game homepage, including Chibi's Home and Play footer links.
- Remove the homepage navigation bars from Chibi and Archie.
- Remove all Archie public Tuning and Gallery pages. Preserve paths for assets used by the game.
- When Play and Install both appear, verify Play precedes Install in the DOM and
  visual order at desktop and narrow widths.

## Outcome

All three homepage changes passed normal gates, CI and deployment.
Browser checks verified Play before Install in DOM and visual order.

- Ada the Navigator deployed `9806b80c01a373de4b19f6922cc0a417bcf3e36d`. Checks at
  320, 390 and 1280 CSS px verified the homepage without a footer. The served
  homepage matched the checked build.
- Archie deployed `2e01ce1704ed8a967c85f22738b68e32c027bfc2`. Checks at 320 and
  1200 CSS px verified the homepage without navigation or a footer. Tuning and
  Gallery return HTTP 404. The Play route and runtime art paths remain available.
- Chibi deployed `126c53a37045f2fbadae735e1901bbcdb7affc04`. Checks at 320 and
  1280 CSS px verified the homepage without navigation or a footer, including
  removal of the Home and Play footer links. Served checks exercised Install and
  verified the Play route.
