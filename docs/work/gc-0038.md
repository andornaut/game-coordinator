## Scope

Simplify public game homepages under the
[shared homepage structure](../design/game-policies.md#game-homepage-structure).
This changes the footer step from gc-0037. Game Tech owners implement and
verify their sites. The playable UI keeps its existing navigation.

## Criteria

- Remove the footer from every game homepage, including Chibi's Home and Play footer links.
- Remove the homepage navigation bars from Chibi and Archie.
- Remove all Archie public Tuning and Gallery pages. Preserve paths for assets used by the game.
- When Play and Install both appear, verify Play precedes Install in the DOM and
  visual order at desktop and narrow widths.
