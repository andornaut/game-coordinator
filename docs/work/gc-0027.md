## Scope

Apply the [Reset save rule](../game-policies.md#saves-and-cheats) in Ada the Navigator, Archie and Chibi
through their existing Tech owners. Archie already matches; Ada and Chibi move Restart and Reset into
Cheats.

## Criteria

- Reset save is the last action in Cheats, with confirmation, and no normal menu, Settings or Start screen
  offers Reset save or Restart.
- Reset save is enabled only when a valid saved game exists, and preserves device preferences.
- Record checked source and normal delivery for each changed game.
