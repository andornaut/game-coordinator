## Scope

Align the homepages for Ada the Navigator, Archie and Chibi using the
[shared homepage structure](../design/game-policies.md#game-homepage-structure).
Each game keeps its own look, art and description. The existing website owners
pair this layout with the Controls section from gc-0036.

## Criteria

- Use a consistent order for the hero and play actions, a short gameplay
  overview, Controls and the footer.
- Condense Archie's long features. Add a compact overview to Ada and Chibi.
- Preserve Play, supported installation, metadata and required links.
- Verify the hierarchy, controls tables and links at desktop and narrow widths.

## Outcome

Ada `03354215`, Archie `86401414`, and Chibi `67578f7f` deployed the shared
section order. Tech verified the compact overview, Controls, and working Play
and Install paths at narrow and desktop widths. Archie used fallback fonts in
the isolated browser preview.
