## Scope

Apply the [Back, Close and Resume policy](../design/game-policies.md#back-close-and-resume)
to mobile browser Back and installed PWA system Back in all games.

## Criteria

- During active, pausable play, platform Back may open Pause or start the existing End walk flow with its guards.
- On bare Start or home, including after returning from play, platform Back opens a prompt with Exit and Cancel. Exit releases the Back guard and proceeds with normal platform Back. Cancel dismisses the prompt and stays on Start.
- Preserve one-layer Back from nested menus and pages, the standalone Exit button visibility rule and the separate paths for Escape, in-game buttons and letterbox dismissal.
- Use the same checked, published Game Kit native Back guard and confirmed-departure API in every game. Game Kit owns browser and installed continuation and unavailable behavior. Game owners retain scene and foreground rules, copy and modal UI.
- Verify both mobile browser and installed PWA behavior where supported.

## Decisions

- D1 (user, 2026-11-27): After an explicit return to Start, let the next platform Back leave directly.
- D2 (user, 2026-11-27; supersedes D1): Always ask whether to exit or stay when platform Back is pressed on bare Start, including after a return from play.
- D3 (user, 2026-11-27): Use the same functionality and Game Kit API across all games.
