## Scope

Apply the [workspace memory ceiling](../game-policies.md#resource-admission) across game and kit launchers, including checks, previews, browser tools and delivery gates. Existing owners qualify their launch configurations. The coordinator verifies the observed limits and any needed idle resident replacement.

## Criteria

- Audit applicable launchers, defaults and overrides. Align memory settings to 4096 MiB or the equivalent Docker value. Keep game-specific build, test, CPU and admission behavior.
- Qualify affected isolated checks and browser flows at the new ceiling. In Chibi, verify the full gate at 4 GiB before operational adoption because the previous gate and local check default were 8 GiB.
- Record exact checked sources and observed container limits or concrete blockers. Preserve admitted source snapshots, controls, active jobs and the delivery cadence.
