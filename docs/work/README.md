# Coordinator work records

This folder contains a `gc-*.md` record for each coordinator request. Its front matter identifies the design area, owner and milestone. The body records scope, criteria, decisions and outcomes as applicable.

Find records by ID or title in the [Coordination](../design/coordination.md#work-items) and [Policies](../design/policies.md#work-items) indexes. Use [the work lifecycle](../game-policies.md#work-lifecycle) to check live progress and evidence in the coordination store. See [Documentation](../README.md) for the workspace guides.
